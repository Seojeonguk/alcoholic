# 공지 알림 보내기 (FCM)

앱은 Firebase Cloud Messaging(FCM)으로 새 버전 · 점검 · 공지 알림을 받아요(#304). 서버(Cloud Functions) 없이 **Firebase 콘솔에서 `announcements` 토픽으로** 보내요. 그래서 기기 토큰을 따로 모으거나 저장하지 않고, 회원 · 비회원 모두 받아요.

## 운영 원칙

- **광고성 알림은 보내지 않아요.** 새 버전 안내, 점검 · 장애 안내, 개인정보처리방침 변경처럼 앱을 쓰는 데 필요한 공지만 보내요.
- 이벤트 · 할인 · 다른 서비스 홍보처럼 영리 목적의 광고성 정보를 보내려면 「정보통신망법」 제50조에 따라 **광고성 정보 수신 동의를 따로** 받아야 하고, 알림 앞에 `(광고)`를 붙이고 수신 거부 방법을 알려야 하며, **밤 9시부터 다음 날 아침 8시까지는 따로 동의를 받지 않으면 보낼 수 없어요.** 앱에는 이런 동의 절차가 없으므로 광고성 알림을 보내지 않아요. 보내야 하면 먼저 동의 절차를 만드는 이슈를 열어요.
- 공지도 꼭 필요할 때만, 낮 시간(오전 9시 ~ 오후 8시)에 보내요.
- 알림에 개인정보(이메일 · 기록 내용)를 넣지 않아요. 토픽 알림은 구독한 모든 기기에 똑같이 가요.

## 앱에서 받는 방식

| 상황                  | 동작                                                                                                                  |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 처음 설치             | 알림이 꺼져 있어요(토픽을 구독하지 않고, 알림 권한도 묻지 않아요)                                                     |
| 첫 기록을 저장한 뒤   | 한 번만 "공지 알림을 받을까요?"를 물어요. "받기"를 누르면 알림 권한을 요청하고 토픽을 구독해요                        |
| 설정 → 공지 알림 켜기 | 알림 권한(Android 13 이상)을 요청하고, 허용하면 토픽을 구독해요                                                       |
| 권한을 거절함         | 스위치가 다시 꺼지고 구독하지 않아요. 시스템 설정에서 허용하도록 안내하고 바로 갈 수 있게 해요                        |
| 설정 → 공지 알림 끄기 | 토픽 구독을 해제하고 기기의 FCM 등록 토큰을 지워요                                                                    |
| 앱이 앞에 떠 있을 때  | 시스템 알림 대신 앱 안의 알림(toast)으로 보여 줘요(FCM은 앱이 앞에 있으면 시스템 알림을 띄우지 않음)                  |
| 알림을 누름           | 앱이 열리고(종료돼 있었으면 처음부터 켜지고, 뒤에 있었으면 앞으로 와요) 공지 내용을 앱 안 알림으로 한 번 더 보여 줘요 |

- 켜고 끈 상태는 기기(AsyncStorage)에 저장해요. 계정과 상관없어서 로그아웃 · 계정 전환에도 그대로예요.
- 앱을 켤 때마다 저장된 상태에 맞춰 구독을 다시 맞춰요(켜져 있는데 시스템 설정에서 알림 권한을 끈 경우에도 구독은 남아 있지만 시스템이 알림을 보여 주지 않아요).
- 알림 채널 이름은 **공지 알림**이에요. 사용자는 시스템 설정에서 이 채널만 끌 수도 있어요.

## 콘솔에서 보내는 방법

1. [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 → **실행(Run) → Messaging**으로 들어가요.
2. **새 캠페인 → 알림(Firebase 알림 메시지)**을 골라요.
3. **알림 제목**과 **알림 텍스트**를 적어요. 예: 제목 `새 버전이 나왔어요`, 텍스트 `스토어에서 업데이트하고 새 기능을 써 보세요.`
4. **타겟**에서 **주제(Topic)**를 고르고 `announcements`를 적어요. 앱(사용자 세그먼트)으로 고르면 공지 토픽과 상관없이 보내지므로 꼭 주제로 보내요.
5. **예약**은 지금 또는 원하는 시간(낮 시간)으로 정해요.
6. **추가 옵션**의 Android 알림 채널은 비워 둬요(앱의 기본 채널 "공지 알림"으로 가요). 맞춤 데이터는 넣지 않아도 돼요.
7. **검토 → 게시**를 눌러요.

### 테스트 메시지 보내기

토픽으로 보내기 전에 내 기기로 먼저 확인해요.

1. 개발용 빌드에서 설정의 **공지 알림**을 켜요.
2. 개발 서버 로그(Metro)에 찍힌 `[FCM] token:` 값을 복사해요. 이 로그는 개발용 빌드(`__DEV__`)에서만 찍혀요.
3. 콘솔의 새 캠페인 작성 화면 오른쪽 **테스트 메시지 전송** → 토큰을 붙여 넣고 **테스트**를 눌러요.
4. 앱이 앞에 있을 때(앱 안 알림), 뒤에 있을 때 · 종료됐을 때(시스템 알림)를 각각 확인해요.

## 관련 파일

- `services/notifications.js`: 권한 요청, 토픽 구독 · 해제, 앞에서 받은 알림 처리
- `lib/notificationSettings.js`: 저장된 상태를 해석하는 순수 함수(단위 테스트)
- `plugins/withNotificationDefaults.js`: 알림 아이콘 · 색상 · 기본 채널 이름을 네이티브 설정에 넣는 config plugin
- `assets/notification-icon.png`: 흰색 단색 알림 아이콘(96×96, 앱 아이콘에서 만듦)
