# Google Play Console 등록

Play Console에서 앱을 처음 등록할 때 채우는 항목과 답을 정리했어요. 앱이 모으는 데이터나 기능이 바뀌면 이 문서와 [개인정보처리방침](privacy-policy.md)을 함께 고치고, 콘솔에도 똑같이 반영해요.

빌드와 업로드 명령은 README의 "빌드 · 배포"를 봐요.

## 출시 순서

1. Play Console에서 **앱 만들기**: 앱 이름 `alcoholic`, 기본 언어 한국어, 앱(게임 아님), 무료.
2. 아래 [앱 콘텐츠](#앱-콘텐츠)와 [스토어 등록정보](#스토어-등록정보)를 채워요.
3. **내부 테스트**에 `production` 빌드 AAB를 직접 올리고, 내 기기에서 설치 · 동작을 확인해요(첫 업로드는 `eas submit`이 안 돼요).
4. **비공개 테스트**(closed testing)를 진행해요. 2023년 11월 13일 이후에 만든 **개인 개발자 계정**은 테스터 **12명 이상**이 **14일 연속**으로 참여해야 프로덕션 출시를 신청할 수 있어요([Google 안내](https://support.google.com/googleplay/android-developer/answer/14151465)). 조직 계정이거나 그 전에 만든 계정이면 건너뛰어요.
5. **프로덕션 액세스 신청** → 승인 후 테스트한 빌드를 **프로덕션**으로 승격해요.

## 앱 콘텐츠

Play Console **정책 및 프로그램 → 앱 콘텐츠**에서 채워요.

### 개인정보처리방침

```text
https://github.com/Seojeonguk/alcoholic/blob/master/docs/privacy-policy.md
```

### 앱 액세스

**일부 기능이 제한됨**을 고르고 심사용 계정을 넣어요. 로그인하지 않으면 첫 화면만 보이기 때문이에요.

- 이메일 인증까지 마친 심사 전용 계정을 하나 만들어요. 사진이 있는 글을 2~3개 써 두면 심사자가 기능을 보기 쉬워요.
- 안내 문구 예시: `첫 화면에서 "로그인"을 누르고 아래 이메일과 비밀번호로 로그인해 주세요.`
- **이 계정으로 탈퇴하지 않아요.** 지우면 심사가 거절돼요.

### 광고

**아니요, 앱에 광고가 없습니다.**

### 콘텐츠 등급

카테고리는 **참고, 뉴스 또는 교육 이외의 모든 앱**(게임 아님)을 골라요. 질문에는 이렇게 답해요.

| 질문                                 | 답                                                      |
| ------------------------------------ | ------------------------------------------------------- |
| 폭력 · 성적 콘텐츠 · 욕설 · 도박     | 아니요                                                  |
| 규제 약물(알코올 · 담배 · 약물) 관련 | **예**: 알코올을 언급 · 묘사함(술 사진과 기록)          |
| 사용자 간 상호작용 · 콘텐츠 공유     | 아니요: 내가 쓴 글은 나만 볼 수 있어요                  |
| 사용자의 위치 공유                   | 아니요: 장소는 직접 적는 글이고 다른 사람에게 안 보여요 |
| 디지털 상품 구매                     | 아니요                                                  |

### 타겟층

**만 18세 이상**만 골라요. 술을 다루는 앱이라 아동 · 청소년을 대상으로 하지 않아요(개인정보처리방침 9번).

### 데이터 보안

[Firebase의 데이터 수집 안내](https://firebase.google.com/docs/android/play-data-disclosure)와 앱 코드를 기준으로 정리했어요. 앱은 Analytics · Crashlytics · 광고 SDK를 쓰지 않아요.

**개요**

| 질문                                            | 답                                                                                                    |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 필수 사용자 데이터 유형을 수집하거나 공유하나요 | 예                                                                                                    |
| 전송 중 데이터가 암호화되나요                   | 예 (Firebase는 HTTPS만 써요)                                                                          |
| 사용자가 데이터 삭제를 요청할 수 있나요         | 예                                                                                                    |
| 계정 생성                                       | 사용자 이름(이메일)과 비밀번호                                                                        |
| 계정 삭제 URL                                   | `https://github.com/Seojeonguk/alcoholic/blob/master/docs/privacy-policy.md#4-계정--데이터-삭제-방법` |
| 계정 없이 일부 데이터만 삭제 요청               | 예 (개인정보처리방침 4번의 이메일로 게시글만 지우기)                                                  |

**수집하는 데이터** — 모두 **공유하지 않음**(Google은 Firebase 처리 위탁이라 공유에 해당하지 않아요), **임시 처리 아님**이에요.

| Play 데이터 유형                  | 앱에서                                      | 필수 · 선택 | 목적                         |
| --------------------------------- | ------------------------------------------- | ----------- | ---------------------------- |
| 개인 정보 → 이메일 주소           | 가입 이메일                                 | 필수        | 계정 관리, 앱 기능           |
| 개인 정보 → 이름                  | 사용자 이름(이메일 앞부분, 인증 메일에 씀)  | 필수        | 계정 관리                    |
| 개인 정보 → 사용자 ID             | Firebase Auth uid                           | 필수        | 계정 관리, 앱 기능           |
| 사진 및 동영상 → 사진             | 게시글 사진                                 | 선택        | 앱 기능                      |
| 앱 활동 → 기타 사용자 제작 콘텐츠 | 제목 · 내용 · 날짜 · 장소(직접 입력) · 태그 | 선택        | 앱 기능                      |
| 기기 또는 기타 ID                 | Firebase Auth가 모으는 IP 주소 · 기기 정보  | 필수        | 사기 방지, 보안 및 규정 준수 |

- **위치**는 고르지 않아요. GPS를 쓰지 않고, 장소는 사용자가 적은 글이라 "기타 사용자 제작 콘텐츠"에 넣었어요.
- 사진은 기기에 저장된 사진 전체가 아니라 사용자가 고른 사진만 올라가요.
- IP 주소를 어느 유형으로 볼지는 Google이 따로 정해 두지 않았어요. 보수적으로 "기기 또는 기타 ID"에 넣었어요.
