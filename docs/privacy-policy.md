# alcoholic 개인정보처리방침

alcoholic(이하 "앱")은 술 사진과 기록을 남기는 앱이에요. 앱은 「개인정보 보호법」에 따라 이용자의 개인정보를 아래와 같이 처리해요.

- 시행일: 2026년 10월 26일

## 1. 처리하는 개인정보

| 구분      | 항목                                                               | 언제 수집하나요                                     |
| --------- | ------------------------------------------------------------------ | --------------------------------------------------- |
| 계정      | 이메일 주소, 비밀번호                                              | 회원가입할 때                                       |
| 계정      | 사용자 이름(이메일 주소의 `@` 앞부분)                              | 인증 메일을 보낼 때 자동으로 만들어요               |
| 기록      | 사진, 제목, 내용, 날짜, 장소, 태그                                 | 이용자가 게시글을 쓰거나 고칠 때                    |
| 자동 수집 | 접속 IP 주소, 로그인 기록, 기기 · 앱 정보(오류 확인에 필요한 범위) | 로그인하거나 서비스를 이용할 때 Firebase가 수집해요 |

- 비밀번호는 Firebase Authentication이 암호화(해시)해서 보관하고, 앱 운영자는 볼 수 없어요.
- **장소**는 이용자가 직접 적은 글이에요. 앱은 기기의 위치 정보(GPS)를 요청하거나 수집하지 않아요.
- **사진**은 이용자가 고르거나 찍은 사진만 올라가요. 앱은 기기의 사진 전체에 접근하지 않아요. 사진 파일에 들어 있는 촬영 정보(메타데이터)가 함께 저장될 수 있어요.
- 광고 식별자를 수집하지 않고, 광고를 보여 주지 않아요.

## 2. 처리 목적

- 회원 가입, 로그인, 이메일 인증, 비밀번호 재설정
- 이용자가 남긴 사진과 기록을 저장하고 이용자 본인에게 보여 주기
- 오류 확인, 부정 이용 방지 등 서비스 운영

## 3. 보유 기간과 파기

- 개인정보는 **회원 탈퇴(계정 삭제)를 요청할 때까지** 보관해요.
- 삭제를 요청하면 계정, 게시글, 올린 사진을 지체 없이(늦어도 30일 안에) 파기해요. 파기한 정보는 되살릴 수 없어요.
- 법령에 따라 보관해야 하는 정보가 있으면 그 기간 동안만 따로 보관해요.

## 4. 계정 · 데이터 삭제 방법

### 앱에서 탈퇴하기

앱의 **설정 → 탈퇴하기**에서 비밀번호를 입력하면 계정, 게시글, 올린 사진이 바로 삭제돼요.

### 앱 없이 삭제 요청하기

앱을 지웠거나 로그인할 수 없으면 아래 이메일로 **가입한 이메일 주소**와 함께 계정 삭제를 요청해 주세요. 본인 확인을 위해 가입한 이메일 주소에서 보내 주셔야 해요. 요청을 받으면 30일 안에 계정, 게시글, 올린 사진을 모두 삭제하고 결과를 알려 드려요.

## 5. 제3자 제공

이용자의 개인정보를 다른 사람이나 회사에 제공하지 않아요. 다만 법령에 따라 수사기관 등이 정해진 절차로 요청하면 제공할 수 있어요.

## 6. 처리 위탁과 국외 이전

앱은 서버를 직접 운영하지 않고 Google의 Firebase를 써요. 그래서 개인정보가 Google의 서버(국외 포함)에 저장돼요.

| 항목               | 내용                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| 이전받는 자        | Google LLC (Firebase)                                                                    |
| 이전되는 국가      | 미국 등 Google 데이터 센터가 있는 국가                                                   |
| 이전 일시 · 방법   | 서비스를 이용할 때마다 네트워크로 전송                                                   |
| 이전 항목          | 1번의 모든 항목                                                                          |
| 이전 목적          | 계정 인증(Firebase Authentication), 기록 저장(Cloud Firestore), 사진 저장(Cloud Storage) |
| 보유 · 이용 기간   | 3번과 같아요                                                                             |
| 이전받는 자 연락처 | [Firebase 개인정보 보호 안내](https://firebase.google.com/support/privacy)               |

국외 이전을 원하지 않으면 회원가입을 하지 않거나 4번의 방법으로 계정을 삭제할 수 있어요. 이 경우 앱을 이용할 수 없어요.
